# 🎨 Web Designer Portfolio

> A modern, responsive web designer portfolio website showcasing creative work, portfolio projects, blog content, and professional information.

## ✨ Overview

**Web Designer Portfolio** is a personal portfolio website created to present web design work, creative projects, professional information, and design-related content in a clean and engaging interface.

The project includes dedicated pages for the main portfolio, about section, blog, individual blog posts, and contact information. The repository is organized with separate folders for styles, JavaScript, images, and fonts.

## 🚀 Features

* 🎨 Modern web designer portfolio
* 🏠 Home page
* 👤 About page
* 💼 Portfolio/projects page
* 📝 Blog page
* 📖 Individual blog post page
* 📩 Contact page
* 📱 Responsive web design
* 🖼️ Image-based portfolio presentation
* 🔤 Custom fonts
* ⚡ JavaScript interactions
* 🎯 Clean and organized frontend structure

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/frankpatel1/Web-Designer-Portfolio.git
```

### Open the project

```bash
cd Web-Designer-Portfolio
```

### Run locally

This is a frontend project and does not require a backend installation.

Open `index.html` directly in your browser, or use **VS Code Live Server** for a local development environment.

## 🎯 Design Goals

The project focuses on:

* **Visual presentation**: Let the work take center stage.
* **Clear navigation**: Make important portfolio sections easy to access.
* **Responsive design**: Provide a consistent experience across screen sizes.
* **Professional presentation**: Create a portfolio suitable for personal branding and client work.
* **Simple structure**: Keep the codebase easy to understand and maintain.
